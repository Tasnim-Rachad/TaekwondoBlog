# TaekwondoBlog
I tried making a magazine on Canvas, but it didn't work out well. So I decided to make a webpage blog.

I am a Taekwondo 1st dan since May 2026. I discovered Taekwondo one day when I was 12 and found a dojang nearby. Not ever since my first training session have I quit. It took me 3 years and a few months to achieve my 1st dan.

# But why?

Because I noticed there wasn't much media content nor a magazine dedicated to girls in martial arts. And if you thought of the following quote like I did, then the reason behind this blog's creation is obvious: 

"If there is a book you want to read but isn't written yet, write it"

Initially, I started my first issue on Canvas but never finished it. Partially due to schoolwork load, partially because it felt like a chore to log into Canvas and use its tools (so I may or may have not purposely avoid dedicating five minutes every day to my magazine attempt). I find it much easier to WRITE my own blog than use a software like Canvas as prime editor.
